# Civil Registry and Certificates

Use this page to identify the right civil-registry record channel before requesting a certificate. The current local registrar contact, fees, documentary requirements, release times, and appointment process are not published here until a current Lal-lo source is reviewed.

## Start with the record you need

- Ask the issuing office whether the request belongs with the **Municipal Civil Registrar** or the Philippine Statistics Authority (PSA).
- Confirm whether the request is for a birth, marriage, death, or another civil-registry record.
- Ask for the current application form, identity requirements, fee schedule, payment channel, and release method.
- Keep the official receipt and request reference if the office provides one.

## Official reference

- [PSA civil registration](https://psa.gov.ph/civil-registration) — national information and certificate channels.
